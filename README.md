# Responsive Coffee Website

A responsive coffee shop website built using HTML, CSS, and JavaScript. This project was created to practice and improve my frontend development skills by building a complete website from scratch.

## About the Project

This is a beginner-friendly coffee website with a clean and responsive design. It includes multiple sections commonly found on a real coffee shop website, along with a responsive navigation menu and footer.

### Sections

- Hero
- About
- Menu
- Testimonials
- Gallery
- Contact
- Navigation Menu
- Footer

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design for desktop, tablet, and mobile
- Responsive navigation menu
- Multiple website sections
- Interactive elements using JavaScript
- Clean and simple coffee shop design

## What I Practiced

Through this project, I practiced:

- Structuring websites with HTML
- CSS Flexbox and Grid
- Responsive design and media queries
- Creating navigation menus
- DOM manipulation with JavaScript
- Making websites work across different screen sizes
- Organizing a complete frontend project
